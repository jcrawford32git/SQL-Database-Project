# SQL Database Project

## Project Overview
This repository demonstrates practical SQL skills using MySQL and MySQL Workbench. The project focuses on retrieving, analyzing, and managing data within relational databases.

## Project: MySQL Database Analysis

**Databases:** LARGECO and MOVIECO  
**Tools:** MySQL, MySQL Workbench  
**Project Type:** Academic SQL Project

### Skills Demonstrated
- SQL queries and data filtering
- INNER JOIN operations across related tables
- Subqueries and aggregate functions (COUNT, SUM, AVG, MAX)
- Data sorting and grouping
- Stored procedures and database triggers
- Relational database management

### Project Highlights
- Retrieved and analyzed customer, employee, product, and sales data.
- Used SQL joins and subqueries to answer business-related questions.
- Developed a trigger to adjust membership balances based on rental late fees.
- Created a stored procedure to generate rental records.

### Project File
`mysql_database_analysis` — SQL queries demonstrating relational database analysis, joins, subqueries, stored procedures, and triggers.
